Get 3D Atom Explorer — interactive 3D Bohr atom models, electron shells, electronic configuration and valency for all 118 elements.

Android App (.apk) — free, no store needed

Download Atom Explorer.apk

Version 1.0.0 • ~1.8 MB • works on Android 5.0+ (API 21)

  1. Tap the download button above. Android will ask to allow installing unknown apps.
  2. Once downloaded, open the file and tap Install.
  3. Open the app — the atom model loads from the web the first time, then works offline.

Heads-up: your phone will warn that the app is from an "unknown source" because it is not distributed through the Google Play Store. This is a safety feature — the app is safe, lightweight, and collects no data.

Install as a Web App (no download, any device)

On Android (Chrome) or iPhone/iPad (Safari), open the site and choose:

  • Chrome: menu → Add to Home screen
  • Safari: Share → Add to Home Screen

It installs like an app with its own icon and works offline after the first visit.

About the Android App
